物理层

物理层核心职责：把比特流 0/1 和物理信号互相转换；定义接口、介质、编码、调制；只传一串 01，不知道这串比特代表帧、MAC、IP、端口，完全不理解上层含义
模型：信源 → 发送器（网卡射频 / PHY 芯片） → 信道 → 接收器（对端 PHY 芯片） → 信宿
介质分为三类：WiFi 空气信道、双绞线铜缆、光纤

去程：手机 → 抖音（只看物理层动作）

1. 手机无线网卡（WiFi）发送信号

上层所有封装完成后，交给物理层的PHY 芯片（物理层芯片）

  1. 上层向下交付一长串连续比特流：0 1 1 0 1 0 0 1 …
  2. 发送器（手机 WiFi 射频模块）：
    用 OFDM 调制，把这串 0、1 映射成不同频率的无线电载波信号（2.4G/5GHz 电磁波）
  3. 信道：空气
    电磁波在空气中传播（会衰减、受干扰：墙体、其他 WiFi 信号）
  4. 路由器 WiFi 天线 = 接收器：捕获电磁波
  5. 接收端 PHY 芯片做解调：把无线电波还原回原始的二进制比特流 0 1 1 0 1 0 0 1 …

✅ 物理层只做：比特 ↔ 无线电波。它不知道这串比特里面包含 MAC、IP，对物理层来说只是一串 0 和 1。

2. 家用路由器 WAN 口（双绞线铜缆，千兆以太网）发送

路由器处理完上层，把新的比特流下发给 WAN 口 PHY 芯片

  1. PHY 拿到比特流，采用PAM 编码（千兆双绞线以太网）
  2. 发送器（路由器网口 PHY）：将编码后的比特转换成差分电压电信号（网线里两根线正负电压）
  3. 信道：超五类 / 六类双绞线
  4. 运营商 R1 设备网口接收器捕获电压信号
  5. 接收 PHY 解码，去除线路编码，还原出原始比特流
  • OFDM：调制电磁波载波的频率 → 发射到空气中（无线）
  • PAM：调制电信号的电压幅度 → 在铜线里面跑差分电压（有线）

3. R1 → R2：运营商骨干光纤链路

  1. R1 的光模块（发送器）接收比特流，做光纤线路编码
  2. 把 0/1 转换为激光光脉冲信号：有光 / 无光代表比特
  3. 信道：单模光纤，光在光纤内部全反射传输，衰减很小，抗电磁干扰强
  4. R2 的光模块接收器：检测光脉冲，把光信号还原成 01 比特

4. R2 → 抖音服务器（光纤）

  1. R2 光发送器：比特流 → 激光脉冲
  2. 信道：光纤
  3. 抖音服务器网卡光接收器：检测光，还原比特流，交付上层。

回程：抖音 → 手机（物理层，反向）

  1. 抖音服务器：比特流下发给光模块发送器 → 激光信号，光纤信道传输到 R2 光接收器 → 还原比特
  2. R2 → R1：光纤，光信号传输，两端光模块完成比特↔光脉冲转换
  3. R1 → 家用路由器 WAN 口：双绞线，PHY 芯片做 PAM 编码，比特↔差分电压
  4. 家用路由器 WiFi 射频（发送器）：比特流进行 OFDM 调制，转为无线电波，空气信道传播
  5. 手机 WiFi 天线接收器：接收电磁波，解调，还原 01 比特流，交给上层

物理层概念单独梳理

  1. 信源：产生原始数据的源头（抖音请求 / 响应数据，上层应用）。物理层不处理数据内容，只接收上层输出的比特序列。
  2. 发送器：PHY 芯片 + 射频 / 光模块 / 网口驱动电路（手机 WiFi 射频、路由器光模块、网口）。作用：比特 → 物理信号
  3. 信道：传输介质
    • 空气（WiFi 无线信道）
    • 双绞线铜线（家用网线）
    • 光纤（运营商骨干）
  4. 接收器：对端的 PHY 芯片、天线、光探测器。作用：物理信号 → 还原二进制比特
  5. 信宿：最终接收数据的应用程序，物理层只管把比特送到上层，不管内容。
  6. 编码：把原始比特流重新编码，适配信道传输
    • 曼彻斯特编码：老式 10M 以太网，现在已经淘汰，考试概念
    • 4B/5B：百兆以太网
    • PAM：千兆双绞线以太网
  7. 调制（无线特有）：WiFi OFDM，把编码后的比特加载到电磁波载波上，无线信道必须调制；光纤 / 铜线有线一般只做线路编码，不用载波调制。

物理层统一规则

  1. 物理层只传输连续的比特序列，完全没有帧概念，分不清哪里是包头、哪里是数据。比特只是一串流，上层链路层才负责划分帧边界。
  2. 每一段独立信道，信号形式完全独立：WiFi 是电磁波、网线是电压、光纤是激光。设备收到比特之后，转发前，会重新编码 / 调制生成全新信号。
  3. 物理层只关心：信号电平、光功率、频率、信噪比、带宽、传输速率、线缆规格，完全不认识 MAC、IP 地址。
